# 📝 Gerenciador de Tarefas

> Aplicação web interativa desenvolvida com **React**, **Vite** e **Tailwind CSS** para gerenciamento simples e eficiente de tarefas diárias.

🔗 **Acesse a aplicação ao vivo:** [gerenciador-de-tarefas-chi-bay.vercel.app](https://gerenciador-de-tarefas-chi-bay.vercel.app/)

---

## 🚀 Funcionalidades
- [x] **Criação, edição e exclusão** de tarefas de forma intuitiva.
- [x] **Status de conclusão:** Marcar e desmarcar tarefas como concluídas.
- [x] **Persistência de Dados:** Salva automaticamente as tarefas no `LocalStorage` do navegador para evitar perda ao recarregar a página.
- [x] **Interface Responsiva:** Estilização moderna e adaptável a telas de celular e desktop com Tailwind CSS.
- [ ] *Em breve:* Filtros por status (todas, pendentes e concluídas).

---

## 🛠️ Tecnologias Utilizadas
- **[React](https://react.dev/)** — Biblioteca JavaScript para construção de interfaces.
- **[Vite](https://vitejs.dev/)** — Tooling de build rápido e otimizado.
- **[Tailwind CSS](https://tailwindcss.com/)** — Estilização moderna através de classes utilitárias.
- **[Vercel](https://vercel.com/)** — Hospedagem e deploy contínuo da aplicação.

## 🔧 Como rodar o projeto localmente

```bash
# Clone este repositório
git clone [https://github.com/PauloGoulartN/Gerenciador-De-Tarefas.git](https://github.com/PauloGoulartN/Gerenciador-De-Tarefas.git)

# Acesse a pasta do projeto
cd Gerenciador-De-Tarefas

# Instale as dependências
npm install

# Execute a aplicação em modo de desenvolvimento
npm run dev
